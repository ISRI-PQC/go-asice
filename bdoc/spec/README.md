# BDOC specification

The BDOC container format for the XML XAdES form of ASiC-E, as used by
the Estonian e-voting collector. The spec document is NOT redistributed
in this repo.

| Specification | Version | Format OID | Official source |
|---|---|---|---|
| BDOC — Format for Digital Signatures (Estonian eID) | 2.1.2:2014 | 1.3.6.1.4.1.10015.1000.3.2.3 | <https://www.sk.ee/repository/bdoc-spec212.pdf> |
